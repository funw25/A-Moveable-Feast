## 写在一切的开始  :D
各位好，这里是funw搭建的开放项目仓库，用于收集同学们自己做的有趣的小玩意：  
网页，AI应用，桌宠，课程项目(及其延伸），个人网站……用于同学们了解彼此都有什么想法和作品，看到每个人的特点。  
不必担心是否完美，是否成熟，是否高大上，它可以是一天赶出来的demo，也可以是持续迭代的产品，只要你觉得好玩，这个作品就是可爱的。  

我们期待开放交流的意愿，项目背后的年轻的声音，有趣的想法，以及真正的学习，勇敢的实践。
你可以在这里展示作品、获得反馈、寻找协作者，也可以通过 Issue、文档和代码贡献参与其他项目。

> 本项目由学生自发创建与维护，不代表任何学院或学校的官方立场， 亦非官方信息发布渠道。


## 📖 这是什么？

这是一个由同学们共同维护的 GitHub 仓库，用于存放和展示学院内所有学生的技术作品。你可以：

- **展示** 自己的项目，为简历增加亮点
- **学习** 同学们的优秀代码和思路
- **交流** 技术心得，找到志同道合的伙伴

我们鼓励 **“开源分享”** 的文化，哪怕只是一个简单的脚本或未完成的实验，都有资格被收录。

## ✍️ 如何上传你的项目？

我们提供两种入口：不熟悉 Git 的同学可以先通过 [项目投稿表单](https://github.com/funw25/A-Moveable-Feast/issues/new?template=submit-project.yml) 登记；熟悉 GitHub 的同学可以直接通过 Pull Request 投稿。完整要求请阅读 [参与贡献指南](CONTRIBUTING.md)。

已经收录的作品可以在 [项目目录](projects/README.md) 中查看。

### 🖥️ 方式一：网页端上传（零基础适用）

1. **Fork 本仓库**：点击右上角 `Fork` 按钮，将仓库复制到你的 GitHub 账号下。
2. **进入你的 Fork**：在你自己的账号下找到刚刚 Fork 的仓库。
3. **新建文件夹**：点击 `Add file` → `Create new file`。
4. **输入完整路径**：在文件名框中填写 `projects/你的项目名-你的用户名/README.md`（例如 `projects/我的第一个网页-zhangsan/README.md`），系统会自动创建文件夹和文件。
5. **编写内容**：在编辑框中粘贴下面的 README 模板，填写你的项目信息。
6. **提交文件**：滚动到页面底部，点击 `Commit new file`。
7. **发起 Pull Request**：回到你 Fork 的仓库页面，点击 `Contribute` → `Open pull request`，然后点击 `Create pull request`。

### 🧑‍💻 方式二：Git 命令行（熟练者）

```bash
git clone https://github.com/你的用户名/A-Moveable-Feast.git
cd A-Moveable-Feast
mkdir -p projects/你的项目名-你的用户名
# 把项目文件复制进去
git add .
git commit -m "添加项目：你的项目名"
git push origin main
# 然后到 GitHub 上发起 Pull Request
```
