# Moveable Feast｜流动的盛宴
>计算机与人工智能学生项目社区  
>***出自海明威的回忆录《流动的盛宴》    
我们的思想在此相遇，如一场流动的盛宴。***  


这里是funw搭建的开放项目仓库，用于收集同学们自己做的有趣的小玩意：网页，AI应用，桌宠，课程项目(及其延伸），个人网站……  
不必担心是否完美，是否成熟，是否高大上，它可以是一天赶出来的demo，也可以是持续迭代的产品。  

我们期待开放交流的意愿，项目背后的年轻的声音，有趣的想法，以及真正的学习，勇敢的实践。
你可以在这里展示作品、获得反馈、寻找协作者，也可以通过 Issue、文档和代码贡献参与其他项目。

> 本项目由学生自发创建与维护，不代表任何学院或学校的官方立场， 亦非官方信息发布渠道。
